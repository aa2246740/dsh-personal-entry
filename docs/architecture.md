# Personal 的职责与扩展方式

Personal 是 DSH 的外部插件，通过官方 `sidebar.panellist` 和 `main` 注册入口与主面板。选中个人时，用公开单一槽位的 priority -100 注册自己的 `sidebar` 和 `shell.leading`；返回工作或插件卸载时释放注册，恢复原有贡献。它不修改官方组件、不隐藏 DOM，也不实现独立登录或模型服务。

`ctx.personal` 是本插件通过 Cordis 提供的客户端服务，不是 DSH 内置 API。它持有功能注册、排序、当前选择、每个功能上次访问的叶子与显式导航次数。功能通过 `ctx.effect(() => ctx.personal.register(...))` 注册，卸载时自动移除；当前功能被移除时返回总览。React 使用稳定快照订阅目录变化。

总壳只接收图标、页面、导航和说明。功能拥有自己的服务、存储和路由，可以单独安装、更新和卸载。OOPS 是这一接口的现有消费者，本仓库不包含 OOPS 业务代码。页面渲染异常由功能级错误边界接住，保留导航。

顶层按 `order` 升序、`id` 次序排序，叶子按 `sections` 声明顺序排列。当前实现没有用户拖动排序、持久化顺序、功能权限沙盒或应用商店；安装其他开发者的功能插件仍意味着信任该插件代码。

## Agent Note：独立仓库与开发依赖

仓库名为 `dsh-personal-entry`，npm/Loader ID 保留 `dsh-personal`，让现有功能插件继续使用同一依赖和类型入口。源码在原插件目录内直接纳入 Git，无需复制整套 OOPS / Harness 工作区。官方依赖链接留在本插件的 node_modules，开发工具可由已有上级目录提供。构建读取已构建的目标 Harness 和非官方 dshx `externalClientBundle`，生成官方客户端所需的 lazy-CJS 注册包；不会构建官方子项目。

仓库验证覆盖注册排序、移除与选中状态、叶子导航、公开 SlotCore 的工作/个人切换和释放。当前发布只整理源码与构建方式，未新增 UI 行为。真实桌面的操作验收需要针对实际安装版本另行记录，不能由单元测试或磁盘产物推断。
