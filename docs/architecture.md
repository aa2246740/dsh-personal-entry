# Personal 的职责与扩展方式

Personal 是 DSH 的外部插件，通过官方 `sidebar.footer.action` 注册入口，通过 `shell.overlay` 注册自己的常驻界面。进入和离开只更新 Personal 的可见状态，工作侧栏、会话、右侧面板和原先选中的全局面板一直保持挂载。它不替换官方组件或操作官方 DOM，也不实现独立登录或模型服务。

0.2.7 的 `main` 切换和 `sidebar` 优先级覆盖会卸载工作树；每次返回都要重新渲染会话与会话列表。`sidebar.panellist` 由官方持有按钮，点击必然选择对应主面板，因此新入口使用允许独立动作的底部槽位。不要通过拦截图标事件、替换 `ctx.layout`、取出官方组件自行渲染等方式恢复旧入口位置。

## 界面结构

- **工作空间**：官方侧栏底部多一个「个人」操作入口。
- **个人侧栏**：顶部是「个人 ▾」下拉菜单空间切换，下面是功能导航。macOS 顶部保留 52px 窗口条和收起按钮，位置与官方侧栏一致；网页版收起后是 56px 图标栏；macOS 与 Windows 收起后隐藏整列。
- **窗口控件**：个人界面内提供 macOS 收起后的「打开侧栏」和「回到工作」。工作侧栏的收起状态不受影响。
- **主面板**：标题栏几何与官方会话标题栏一致（10px 内边距 + 30px 标题行）；Windows 隐藏侧栏时标题栏出现打开按钮。其下是功能页面，访问过的功能在回到工作后也保持挂载。
- **焦点与输入**：原生 `dialog.showModal()` 使工作树暂时不可交互，`close()` 恢复焦点。关闭不卸载 React 树。菜单先处理 Escape；空间本身通过显式菜单或可配置快捷键退出。仅打开时声明 `aria-modal`，避免隐藏状态拦截工作快捷键。
- **冷启动与内存**：首次打开才挂载功能；打开过的功能继续占用内存，后台业务仍由功能插件负责。卸载功能会移除其组件，卸载 Personal 会关闭 dialog 并释放整个个人树。

没有总览目录页。默认功能是排在最前的功能，这样用户自己的总览可以作为普通功能插件实现，而不是由总壳展示插件列表。

## 服务与状态

`ctx.personal` 是本插件通过 Cordis 提供的客户端服务，不是 DSH 内置 API。它持有功能注册、排序、用户明确打开的功能、每个功能上次访问的叶子与显式导航次数。功能通过 `ctx.effect(() => ctx.personal.register(...))` 注册，卸载时自动移除。被打开的功能是一个偏好：暂未注册时显示第一个功能，重新注册后恢复。React 使用稳定快照订阅目录变化。

位置和分组折叠状态存于浏览器本地存储（`dsh-personal.location.v1`、`dsh-personal.collapsed.v1`），所有读写都容错，失败时只是不记忆。总壳只接收图标、页面、导航和说明；功能拥有自己的服务、存储和路由，可以单独安装、更新和卸载。OOPS 是这一接口的现有消费者，本仓库不包含 OOPS 业务代码。

## 升级鲁棒性

- 运行时产物只 `require` React；官方包仅用于类型检查，官方组件更新不会与本插件打包的副本冲突。
- 所有颜色、圆角、焦点环和动效读取 DSH 主题变量（`--dsw-*`、`--ds-ease-in-out`），并带兜底值；平台差异只依赖框架公布的 `html[data-platform]`、`[data-windows-titlebar]`、`[data-fullscreen]` 与 `[data-ds-dark-theme]`。
- `ctx.slots.inject` 在槽位声明出现（或官方插件热重载后重新声明）时才注册；个人组件不持有官方工作组件的渲染权限。
- 功能页面、功能图标各自有错误边界。
- 快捷键通过 `ctx.inject(['shortcuts'])` 按需接入，命令默认不绑定按键，接口不符时跳过。
- 界面文字通过 `ctx.locale.getLocale()` 选择中文或英文，语言服务不可用时默认中文。

已知限制：个人模式下官方工作界面不可交互，回到工作后即可打开官方设置。个人侧栏采用独立的 280px 列，收起状态不与工作同步；较窄视口使用抽屉，背景为主题侧栏填充色。跨文档 iframe 内的浮层照常工作；同文档的 React portal 必须使用传入的 `portalContainer`，直接挂到 `document.body` 的旧功能需要适配原生 dialog 的顶层规则。当前没有用户拖动排序、功能权限沙盒或应用商店。

## Agent Note：独立仓库与开发依赖

仓库名为 `dsh-personal-entry`，npm/Loader ID 保留 `dsh-personal`，让现有功能插件继续使用同一依赖和类型入口。官方依赖链接留在本插件的 node_modules，开发工具可由已有上级目录提供。构建读取已构建的目标 Harness 和非官方 dshx `externalClientBundle`，生成官方客户端所需的 lazy-CJS 注册包；不会构建官方子项目。

仓库验证覆盖注册排序、默认功能、移除与恢复、位置记忆和叶子导航。离线浏览器测试加载实际客户端构建，在最小 Host 适配器下比较生命周期、状态保留、焦点和卸载。它不运行完整官方 Host；真实客户端验收单独记录，不能由单元测试或磁盘产物推断。

个人空间使用当前空间下拉菜单，支持方向键、Home/End、Escape、Tab 和点击外部关闭。不向官方图标槽嵌套按钮。交互约束见根目录 DESIGN.md。
